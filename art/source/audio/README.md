# Selected runtime sound recordings

`catalog.json` pins the 24 selected playback recordings, their exact paths, SHA-256 hashes, sizes, audition labels and sources. `npm run art:audio` embeds them once into `src/assets/audio-samples.js`; ordinary builds and play need no network or encoder. The original pain WAV is referenced from its retained original directory; the 23 files here are 96-kbit/s stereo MP3 playback copies. Rejected alternative auditions are not part of this catalog.

The selected C1–C6, C7-A, C8-D, provisional C9-B, C10-B, C11 and C12-A/B are the exact audition playback bytes (including C8-D's final headroom-adjusted encode). Their source/construction details remain pinned in `art/source/audio-candidates/`. Runtime gain and a shared overlap compressor are separate from the retained file bytes.

Kenney sources: [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds), [Interface Sounds](https://kenney.nl/assets/interface-sounds) and [Digital Audio](https://kenney.nl/assets/digital-audio); downloaded CC0 license notices are retained alongside this note. The Impact notice is also retained from the original broader audition pack; no rejected Impact-only candidate is embedded. CC0 permits the processed excerpts/layers.

Freesound CC0 sources: rocket effect by [LimitSnap_Creations](https://freesound.org/people/LimitSnap_Creations/sounds/318688/), metal crash by [moxobna](https://freesound.org/people/moxobna/sounds/40158/), rock-wall effect by [spookymodem](https://freesound.org/people/spookymodem/sounds/202098/), thunder by [BlueDelta](https://freesound.org/people/BlueDelta/sounds/446753/) and heavy doors by [Sheyvan/Philipp Grzemba](https://freesound.org/people/Sheyvan/sounds/524231/) ([second recording](https://freesound.org/people/Sheyvan/sounds/524284/)). These use the legitimate public high-quality preview MP3s, not authenticated lossless originals. Source preview hashes and license links are retained in the audition manifests. No claim of independently hearing these clips is made; assignments follow the author's feedback.

The original Prospector W1–W5, alarms, landing, start, wormhole and pain recordings have separate [upstream provenance and license/credit limits](../prospector/audio/README.md); they are **not claimed as CC0**. Their original WAVs are retained separately. W5 uses the already-auditioned 96-kbit/s comparison; the other new original playback copies use FFmpeg/libmp3lame at 96 kbit/s, 44.1 kHz stereo without trimming, pitch change or gain processing. Original pain stays byte-identical WAV. FFmpeg/imageio-ffmpeg are optional development helpers, not shipped executables or runtime dependencies.

The original wormhole recording is bundled/reserved, because the game currently has no wormhole-travel action. Existing gameplay routing, caches, size budget and validation limits are documented in [docs/audio.md](../../../docs/audio.md). This local integration does not publish anything to GitHub.
